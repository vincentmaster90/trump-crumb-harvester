How to read the test

Performance metric guide

Start price = price when that bot began the test. Buy price = purchase price of the current cycle; after every harvest it resets to the new re-entry price. Current price = live market price. Target price = price required for the next harvest. Cycle move = current move from the latest buy price. To harvest = how much price still needs to rise to trigger the next cash-out. Unrealized = profit/loss still inside the open position. Withdrawn = cash already harvested out. Economic value = active wealth + withdrawn cash. Bot vs Hold = whether harvesting is beating simply holding the same crypto from test start.
